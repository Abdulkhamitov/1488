Ответы на вопросы

1. Какое свойство включает CSS Grid и чем отличается от Flexbox?
`display: grid`. Grid — двумерная система (строки + колонки одновременно). Flexbox — одномерная (одна ось за раз).

2. Разница между `grid-template-columns` и `grid-auto-columns`?
`grid-template-columns` задаёт явные колонки. `grid-auto-columns` — размер колонок, создаваемых неявно (когда элементы выходят за пределы шаблона).

3. Что делают `repeat()`, `minmax()`, `auto-fit`?
- `repeat(3, 1fr)` — три одинаковые колонки.
- `minmax(200px, 1fr)` — колонка не меньше 200px и не больше 1fr.
- `auto-fit` — автоматически подбирает число колонок.

4. Как работают именованные grid-области?
Через `grid-template-areas` задаётся «карта» макета, а элементы размещаются в ней через `grid-area: имя`. Удобно для крупных макетов — сразу видно структуру.

5. Система нумерации grid-линий?
Линии нумеруются с 1. `grid-column: 1 / 3` — элемент от первой до третьей линии (занимает 2 колонки). `grid-row` — аналогично по строкам.

6. `gap` vs `margin`?
`gap` создаёт промежутки только между ячейками, не влияет на внешние края и работает симметрично. `margin` нужно задавать каждому элементу и компенсировать у краёв.

7. Как `justify-items` и `align-items` влияют на grid-элементы?
`justify-items` — выравнивание по горизонтали внутри ячейки. `align-items` — по вертикали. Можно задавать индивидуально через `justify-self`/`align-self`.

8. Разница между `auto-fill` и `auto-fit`?
`auto-fill` создаёт максимально возможное число колонок (даже пустых). `auto-fit` сжимает пустые и растягивает существующие. Для галерей обычно `auto-fit`.

9. Как создать сложные макеты через `grid-template-areas`?
Области описываются визуально, одинаковые имена формируют одну зону:
grid-template-areas:
"header header"
"nav main"
"footer footer";
Правила: имена без пробелов; `.` = пустая ячейка; одна область — прямоугольник.

10. Преимущества CSS Grid?
Двумерность, точный контроль строк и колонок, `grid-template-areas` для читаемости, вложенные сетки, простая адаптивность через `auto-fit`/`minmax`.
