Ответы на вопросы 

1. HTML5-атрибуты:** `required`, `minlength`, `maxlength`, `pattern`, `type`, `min`, `max`.
2. `novalidate` отключает встроенную валидацию браузера, но позволяет использовать JavaScript для кастомной валидации.
3. Связь `<label>` с полем через атрибут `for` (равный `id` поля) важна для доступности — скринридеры озвучивают подпись.
4. Типы полей: `email` для email, `tel` для телефона, `password` для пароля, `date` для даты.
5. `pattern` задаёт регулярное выражение для проверки ввода. Используется для сложных форматов (телефон, пароль).
6. События: `input` (при вводе), `blur` (при потере фокуса), `submit` (при отправке). Используются для валидации в реальном времени.
7. Доступность сообщений об ошибках:** использовать `aria-describedby`, `role="alert"`, связывать сообщение с полем.
8. `<fieldset>` и `<legend>` группируют связанные поля, что улучшает структуру и доступность формы.
9. Кастомная валидация: сравнение значений полей (пароль и подтверждение), проверка через JavaScript.
10. CSS-методы:** `:valid`, `:invalid`, `:focus`, `:required` для визуального отображения состояний полей.
