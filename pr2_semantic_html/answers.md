Ответы на вопросы для самоконтроля

1. Чем семантическая верстка отличается от несемантической и почему она важна?
Семантическая вёрстка использует теги по их смыслу (`<header>`, `<article>`, `<nav>`), а несемантическая — обёртки `<div>`/`<span>` без значения. Семантическая важна для доступности (скринридеры), SEO (поисковики понимают структуру) и поддерживаемости кода.

2. В каких случаях следует использовать `<article>` вместо `<section>`?
`<article>` — для самостоятельного, самодостаточного контента (пост, новость, карточка товара). `<section>` — для тематического блока внутри статьи или страницы. В моей работе `<article>` — это «Солнечная система» и «Дальний космос», а `<section>` — подразделы «Марс», «Юпитер», «О проекте».

3. Для чего предназначены теги `<header>` и `<footer>` и могут ли они использоваться несколько раз?
`<header>` — вводная часть раздела/страницы. `<footer>` — завершающая часть. Да, могут использоваться несколько раз: один `<header>` у страницы, ещё один — внутри `<article>`.

4. Какой тег использовать для основного контента и почему не `<div>`?
`<main>` — он явно указывает на главное содержимое страницы (должен быть один). `<div>` — нейтральный контейнер без смысла; для поисковиков и скринридеров он не даёт информации о назначении блока.

5. В чём разница между `<nav>` и обычным списком ссылок?
`<nav>` — семантический контейнер для основных навигационных блоков. Обычный список ссылок — это просто `<ul>`. `<nav>` обязателен, когда ссылки образуют блок навигации по сайту или разделу.

6. Для чего используется атрибут `datetime` в теге `<time>`?
`datetime` хранит машиночитаемую дату (`2025-03-12`). Это важно для поисковых систем, парсеров и микроразметки.

7. Какие преимущества дают `<figure>` и `<figcaption>`?
Они семантически связывают изображение и подпись: скринридеры и поисковики понимают, что это единый смысловой блок.

8. Когда следует использовать `<aside>`?
`<aside>` — для контента, косвенно связанного с основным: боковые панели, виджеты, реклама, «читайте также».

9. Как семантическая разметка влияет на SEO и доступность?
Поисковики лучше понимают структуру → выше релевантность. Скринридеры используют семантические роли для быстрой навигации.

10. Какие теги вы использовали для улучшения структуры документа?
`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>`, `<figure>`/`<figcaption>`, `<details>`/`<summary>`, `<time>`, `<address>`.
