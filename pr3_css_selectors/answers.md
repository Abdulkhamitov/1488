Ответы на вопросы

1. Разница между селектором по классу и по ID?
Класс можно применять ко многим элементам, ID — уникален для одного. Специфичность: класс (0,1,0) < ID (1,0,0). Классы гибче, ID чаще используют для JS-хуков.

2. Как работает каскад?
Правила применяются в порядке: важность (`!important`) → происхождение (стили браузера → пользователя → автора) → специфичность → порядок объявления (последнее правило побеждает).

3. Специфичность:
- `ul li.important` → 0,1,2
- `#site-title` → 1,0,0
- `.content > .featured-post` → 0,2,0

4. Наследуемые свойства (3): `color`, `font-family`, `line-height`.
Ненаследуемые (3):** `border`, `padding`, `margin`.

5. Разница между `>` и пробелом?
`>` — только прямые дети. Пробел — все потомки на любой глубине.

6. `:hover` и `:nth-child()`?
`:hover` — стиль при наведении. `:nth-child()` — выбор элементов по позиции (чётные/нечётные, формула). Применяются в меню, таблицах, списках.

7. Что делает `!important`?
Перекрывает все остальные правила, кроме других `!important` с той же специфичностью. Использовать осторожно — усложняет поддержку.

8. Псевдоэлементы `::before`/`::after`?
Добавляют контент до/после элемента через свойство `content`. Могут содержать текст, символы, изображения.

9. Порядок при равной специфичности?
Побеждает правило, объявленное **позже** в файле (или в подключённом позже файле).

10. DevTools для CSS?
Показывают применённые стили, зачёркивают переопределённые, позволяют менять значения в реальном времени и видеть специфичность.
